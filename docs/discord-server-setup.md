# Discord Server 設定步驟

這份教你建一個自己的 Discord Server、一個給 agent 用的頻道、拿到 `CHANNEL_ID`，並準備好測試用的邀請連結。電腦是 Windows。

Discord 常改版，畫面上的字可能和這裡有一點出入。我在括號裡附了英文名稱，方便你對照。

## 事前準備

- 一個 Discord 帳號（你自己的）。用瀏覽器開 <https://discord.com/app> 或用桌面版 App 都可以，下面以電腦版為準。
- 另一個 Discord 帳號（第二個帳號，測試用，見第 4 節）。

## 1. 建立你自己的 Server

1. 打開 Discord，看畫面**最左邊**那一排圓形圖示。
2. 點那一排最下面的 **＋**（新增伺服器 / Add a Server）。
3. 選 **自製**（Create My Own）。
4. 選 **供我和我的朋友使用**（For me and my friends）。
5. 在「伺服器名稱」欄位填一個名字，例如 `比價測試`。圖示可以不傳。
6. 點 **建立**（Create）。

做完後，最左邊那一排會多一個你剛建的 Server，畫面也會自動切到它。

> 你是這個 Server 的建立者，也就是「擁有者」。擁有者自動擁有所有權限，包括「管理伺服器」（Manage Server）。見第 5 節。

## 2. 建立給 agent 用的頻道

1. 在左邊看你的 Server 名稱（畫面左上角）。底下有「文字頻道」（Text Channels）這個分類。
2. 把滑鼠移到「**文字頻道**」這幾個字上，右邊會出現一個 **＋**，點它。
3. 頻道類型選 **文字**（Text）。
4. 「頻道名稱」填 `比價`。
5. **不要**打開「私人頻道」（Private Channel）。如果打開了，bot 和別人都看不到，之後要另外設定。
6. 點 **建立頻道**（Create Channel）。

做完後，「文字頻道」底下會多一個 `#比價`。

## 3. 拿到 CHANNEL_ID

`CHANNEL_ID` 是 Discord 給這個頻道的一串數字。要先打開「開發者模式」才看得到。

### 3-1. 打開開發者模式

1. 點畫面**左下角**你的頭像旁邊的**齒輪**（使用者設定 / User Settings）。
2. 在左邊清單往下找 **進階**（Advanced）。（在較新的版本裡，它可能在「App 設定」那一組底下。）
3. 把 **開發者模式**（Developer Mode）打開。
4. 按右上角的 **Esc** 或 **✕** 離開設定。

### 3-2. 複製頻道 ID

1. 在左邊的頻道清單，對 `#比價` 按**滑鼠右鍵**。
2. 選最下面的 **複製頻道 ID**（Copy Channel ID）。
3. 打開 Windows 的**記事本**，按 **Ctrl + V** 貼上，你會看到一串 17 到 20 位的數字，例如 `123456789012345678`。
4. 把這串數字填進 `.env` 的 `CHANNEL_ID=` 後面（等號後面直接接數字，沒有空格、沒有引號）。

> `CHANNEL_ID` 不是機密，貼給別人沒關係。要保密的是 bot token，那在另一份文件。

## 4. 產生邀請連結，邀請第二個帳號測試

後面測試要用兩個帳號（A 是你，B 是第二個帳號），所以要有邀請連結。

### 4-1. 產生連結

1. 對左邊那一排的 Server 圖示，或畫面左上角的 Server 名稱，點一下（或按右鍵）。
2. 選 **邀請其他人**（Invite People）。
3. 在跳出的視窗，點右下角的小齒輪（**編輯邀請連結** / Edit invite link）。
4. 「**邀請連結到期時間**」選 **永不**（Never）。
5. 「**使用次數上限**」選 **無限制**（No limit）。
6. 點 **產生新連結**（Generate a New Link）。
7. 點 **複製**（Copy）。連結長得像 `https://discord.gg/xxxxxxx`。

> 邀請連結拿到的人就能加入你的 Server，所以不要貼到公開的地方。測完之後可以回到同一個畫面刪掉或讓它過期。

### 4-2. 用第二個帳號加入

第二個帳號不能跟你現在登入的同時用在同一個瀏覽器視窗，請用下面其中一種：

**做法 A：用瀏覽器的無痕視窗（最簡單）**

1. 在 Chrome 按 **Ctrl + Shift + N** 開一個無痕視窗（Edge 是 Ctrl + Shift + N，Firefox 是 Ctrl + Shift + P）。
2. 在網址列輸入 `discord.com/app`，登入**第二個帳號**。
3. 把剛剛複製的邀請連結貼到無痕視窗的網址列，按 Enter。
4. 點 **接受邀請**（Accept Invite）。

**做法 B：用手機**

1. 手機裝 Discord，登入第二個帳號。
2. 把邀請連結傳給手機（例如用 LINE 傳給自己），在手機上點開，按 **接受邀請**。

做完後，在你自己的畫面左側的成員清單（右邊欄位，或按右上角的人形圖示）會看到第二個帳號出現。

## 5. 之後評分的 Scorer 也要被邀請

之後評分的 Scorer 也要被邀請進這個 Server。要邀請別人，邀請者需要有「**管理伺服器**」權限。

- 你是這個 Server 的建立者，所以已經有這個權限，**不用另外設定**。
- 如果要確認：在 Server 名稱旁點一下，如果選單裡看得到 **伺服器設定**（Server Settings），就代表你有管理權限。
- 之後邀請 Scorer 的方式和第 4-1 一樣：把邀請連結給對方（記得連結要設成「永不到期、無限制」，否則對方點開時可能已經失效）。
- 這個 Server **不要轉讓**給別人，也不要把自己的身分組降掉，否則你就沒有管理伺服器權限了。

## 完成時你應該有

- 一個你自己的 Server
- 一個 `#比價` 頻道
- 一串 `CHANNEL_ID`（已填進 `.env`）
- 一條永不到期的邀請連結
- 第二個帳號已經加入
- 下一步：照 `docs/discord-bot-setup.md` 建 bot 並邀進這個 Server
