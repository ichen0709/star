# 需求說明

## 這是什麼
一個在我自己電腦上執行的 Discord agent，叫「單價比價員」。只要它開著，指定頻道裡有人傳貨架標價牌或商品的照片，它就辨識品名、價格、容量，換算成每 100g（或每 100ml、每個）的單價，和同一個人之前記錄過的同類商品比較，回覆哪個比較划算。agent 關掉就不處理。

這不是食物熱量或營養的 agent，不做那方面的事。

## 誰會用
我 Discord Server 裡、那個指定頻道的任何人，用手機或電腦都可以傳。每個人的紀錄分開，只跟自己的歷史比較。

## 使用的流程
1. 有人在頻道裡傳一張標價牌或商品照片
2. agent 收到，先回一個「處理中」的提示
3. agent 辨識品名、價格、容量
4. agent 換算成每 100g／每 100ml／每個的單價
5. agent 找出這個人之前記錄過的同類商品，比較單價
6. agent 把這筆記下來、把照片存起來
7. agent 回覆上傳者辨識結果、單價、比較結論

## 功能

### 確定要做
- 辨識照片上的品名、價格、容量
- 換算單價（每 100g／每 100ml／每個）
- 和同一個人的歷史同類商品比較，回覆哪個划算
- 各人分開記錄

### 預計之後做，細節待決定
- 查詢自己的紀錄
- 修正自己的紀錄（辨識錯時）
- 定時週報

## 要記錄的內容（存成一個可以一直往下加的 Excel 檔）
- 日期時間
- 上傳者
- 品名
- 價格
- 容量與單位
- 換算後單價（每 100g／100ml／個）
- 店家或地點（照片上看得到才記，看不到就空著）
- 照片存放位置

照片另外存進一個資料夾，檔名用「日期時間 + 品名簡稱」。

## 看不清楚、或不是標價牌／商品的時候
回覆說明原因，請對方重傳，不建檔。例如「價格被遮住了，請重拍」；如果不是標價牌或商品，就說明看到的是什麼。

## 回覆上要有
- 收到時先有「處理中」的提示
- 處理完回覆：辨識結果（品名、價格、容量）、換算單價、和歷史同類商品比較的結論
- 沒有同類歷史紀錄時，回覆這是第一筆

## 不做的
- 營養、熱量分析
- 註冊、登入、網頁後台
- 雲端長時間服務（這是一支開著才會動的本機程式）
- 自動爬網路上的價格，只比我自己記錄過的

## 技術上我知道的
- 用 Python 3.12 + uv
- 照片用 `claude -p` 在我這台電腦上處理
- Discord 用 Gateway（bot）模式，不需要 ngrok
- 紀錄存成一個可以持續往下加的 Excel 檔
- 設定放在 `.env`

## 做事的順序
1. 先做防護：`.env` 讀取、暫存資料夾、`claude -p` 權限限制、輸入與輸出檢查
2. 單張辨識 + 換算單價
3. 加存檔與歷史比較
4. 最後才是查詢、修正與週報

每一步都要能單獨測試。
